# ⚡ Konverter Teks ke HTML

> Alat bantu web responsif untuk mengonversi teks mentah berformat menjadi markup HTML semantik yang bersih, rapi, dan siap pakai.

[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=flat-square&logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)
[![HTML5](https://img.shields.io/badge/HTML5-Semantic-E34F26?style=flat-square&logo=html5&logoColor=white)](https://html.spec.whatwg.org/)
[![Deploy](https://img.shields.io/badge/Deploy-Netlify-00C7B7?style=flat-square&logo=netlify&logoColor=white)](https://www.netlify.com/)

---

## 🚀 Fitur

- 🔄 **Real-Time / Instant Convert**: Mengubah baris teks, paragraf, list, dan heading menjadi elemen HTML yang valid secara instan.
- 🧹 **Clean Code Output**: Menghasilkan markup yang teratur tanpa inline-style berlebih.
- 📋 **Satu Klik Salin**: Tombol cepat untuk langsung menyalin hasil HTML ke clipboard.
- 📱 **Mobile & Desktop Friendly**: Antarmuka adaptif menggunakan Tailwind CSS.

---

## 🛠️ Panduan Penggunaan

1. Buka aplikasi di browser (buka `index.html`).
2. Tempelkan teks yang ingin diformat ke kolom input kiri.
3. Klik tombol konversi.
4. Salin kode HTML bersih yang muncul di panel hasil.
