# ⚡ Text to Clean HTML Converter

> Responsive web tool for converting formatted raw text into semantic, production-ready HTML code.

---

## 🚀 Features

- 🔄 **Instant Conversion**: Converts paragraphs, lists, headings, and formatting into valid HTML in real time.
- 🧹 **Clean Markup**: Produces clean, readable output without excessive inline styling.
- 📋 **One-Click Copy**: Fast clipboard action to copy formatted HTML instantly.
- 📱 **Mobile & Desktop Friendly**: Adaptive interface styled with Tailwind CSS.
